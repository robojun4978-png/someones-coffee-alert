# 썸원스커피 지원 알리미 (PWA)

스마트폰 홈 화면에 추가해 쓰는 로그인 없는 웹앱입니다. 화면은 목록/상세 두 단계이며, 큰 글자와 큰 버튼을 사용합니다.

## 꼭 알아두실 점

- 이 프로젝트는 **운영 가능한 기본 골격**입니다. 기업마당 API 자동 수집을 연결했고, 대전 기관별 게시판은 기관마다 API/RSS/화면 구조가 달라 일괄 자동 수집이 보장되지 않습니다. 원문에서 확인한 지역·업종·자격·마감 조건을 `data/manual_items.json`에 추가해 주세요.
- 기업마당 데이터의 공고문 문장만으로 업종 적합성·지역 적합성·업력 조건을 완벽하게 판정할 수 없습니다. 자동 수집은 보수적으로 일부만 통과시키며, **신청 전 원문 확인은 필수**입니다.
- 대출은 자동으로 추정하지 않습니다. `manual_items.json`에 등록할 때 원문에서 금리 0% 또는 이차보전 후 실제 부담금리 0%가 확인되어야 노출됩니다. 1% 이상 또는 불명확한 대출은 등록하지 마세요.
- 연매출/업력/자가 상가 정보는 앱이 자격을 확정하는 근거가 아닙니다. 개별 공고의 세부 요건을 확인해야 합니다.
- 예시 항목은 `verified:false`이므로 실제 목록에 나오지 않습니다.

## 1. API 키 발급

### 기업마당 (우선 연결)
1. https://www.bizinfo.go.kr/apiList.do 접속
2. **지원사업정보 API** 선택 후 사용신청
3. 신청서에 기관/기업명, 담당자, 이메일, 전화번호, 시스템명, 시스템 IP/URL 등을 입력
4. 발급된 인증키를 이메일에서 확인
5. GitHub 저장소의 `Settings → Secrets and variables → Actions → New repository secret` 선택
6. 이름은 `BIZINFO_KEY`, 값은 발급받은 키를 입력하고 저장

기업마당 API 주소는 `https://www.bizinfo.go.kr/uss/rss/bizinfoApi.do`이며 JSON 요청을 사용합니다. 키를 HTML/JavaScript에 직접 넣지 마세요.

### 공공데이터포털
1. https://www.data.go.kr 회원가입 및 로그인
2. 필요한 API의 상세 페이지에서 **활용신청**
3. 승인 후 마이페이지의 개발계정 인증키 확인
4. API별 상세 페이지의 요청주소/필수 파라미터/응답 필드를 확인
5. 이 저장소의 수집기에 추가하려면 `scripts/collect.py`에 별도 연결 코드를 넣어야 합니다. 공공데이터포털 키는 API마다 권한과 서비스가 다르므로 기업마당 키와 서로 바꿔 쓸 수 없습니다.

추천 확인 대상: 중소벤처기업부 중소기업 지원사업 공고 조회 서비스(데이터 ID 15157820). 모든 공공데이터 API가 소상공인 지원사업을 제공하는 것은 아닙니다.

### 소상공인24 및 대전 지역기관
- 소상공인24: https://www.sbiz24.kr
- 대전광역시: https://www.daejeon.go.kr
- 대전신용보증재단: https://www.sinbo.or.kr
- 대전일자리경제진흥원: https://www.djbea.or.kr
- 대전 중구청: https://www.djjunggu.go.kr

각 사이트의 지원사업/공지/고시공고 메뉴에서 API 또는 RSS 제공 여부를 확인하세요. 별도 공개 API가 없거나 이용조건이 불명확하면 무단으로 화면을 긁어오지 말고, 원문 확인 후 `manual_items.json`에 등록하는 방식이 안전합니다.

## 2. 공고를 수동으로 추가하는 방법

`data/manual_items.json`을 열고 `items` 배열에 항목을 추가합니다. 아래 기준을 지켜 주세요.

- `verified`: 원문을 직접 읽고 조건을 확인했으면 `true`
- `type`: 지원금/사업은 `grant`, 대출은 `loan`
- `region`: `전국`, `대전광역시`, `대전 중구` 중 하나
- `sector`: 일반음식점 신청 가능 여부를 원문에서 확인한 경우에만 `일반음식점`
- 대출은 `effectiveZero:true`, `rateEvidence:"원문에서 실질 0% 확인"` 모두 필요
- 금액/날짜가 원문에 없으면 빈 값으로 두세요. 화면에 `원문 확인`으로 표시됩니다.
- `deadline`은 `YYYY-MM-DD` 형식입니다.

예시:
```json
{
  "id": "daejeon-2026-001",
  "type": "grant",
  "title": "공고 원문에 적힌 사업명",
  "kind": "경영지원",
  "deadline": "2026-11-30",
  "amount": "최대 100만원",
  "summary": "가게 운영에 필요한 비용 일부를 지원합니다. 자세한 사용처와 증빙은 공고문에서 확인하세요.",
  "url": "https://기관의-실제-공고-주소",
  "applyUrl": "https://실제-신청-주소",
  "region": "대전 중구",
  "sector": "일반음식점",
  "priority": true,
  "verified": true
}
```
실제 URL과 원문 근거가 확인된 경우에만 저장하세요.

## 3. GitHub에 올리고 무료 배포

1. https://github.com 에 로그인하고 `New repository`를 누릅니다. 저장소 이름은 `someones-coffee-alert`, 공개(Public)로 만듭니다.
2. 이 압축파일을 풀고 파일 전체를 저장소 최상위에 업로드합니다. `.github` 폴더도 반드시 포함합니다.
3. 저장소 `Settings → Secrets and variables → Actions`에서 `BIZINFO_KEY` 비밀값을 추가합니다.
4. `Settings → Pages → Build and deployment → Source`에서 **GitHub Actions**를 선택합니다.
5. `Actions` 탭에서 **주간 공고 수집 및 배포**를 선택하고 `Run workflow`를 눌러 첫 수집을 시험합니다.
6. 실행이 성공하면 `Settings → Pages`에 표시된 주소로 앱을 엽니다.

GitHub Pages는 공개 사이트입니다. API 키는 절대로 저장소 파일이나 `app.js`에 넣지 말고 GitHub Secrets에만 저장하세요.

## 4. 월요일 자동 업데이트

- `.github/workflows/weekly.yml`: 매주 월요일 오전 7시(KST)에 실행되도록 UTC 일요일 22시에 예약했습니다.
- 수집 성공 시 `data/items.json`을 갱신하고 사이트를 다시 배포합니다.
- 수집 실패 시 기존 `items.json`을 덮어쓰지 않으므로 지난 자료가 유지됩니다.
- GitHub Actions 예약 실행은 지연될 수 있으므로 정확히 07:00:00에 실행된다고 보장되지는 않습니다.

## 5. 월요일 오전 8시 알림 (간편 선택: ntfy)

웹 푸시나 카카오톡 나에게 보내기는 브라우저 권한/카카오 OAuth 토큰 관리가 필요합니다. 초보 운영자가 가장 간단히 설정할 수 있는 대안으로 ntfy 알림을 선택해 두었습니다. 휴대폰에 ntfy 앱을 설치하고 비공개로 추측하기 어려운 토픽명을 만들어 구독한 뒤:

1. GitHub 저장소 `Settings → Secrets and variables → Actions → New repository secret`
2. 이름 `NTFY_TOPIC`, 값은 만든 토픽명 입력
3. 매주 월요일 08:00 KST에 건수를 알림으로 받습니다.

주의: ntfy.sh 공개 서버의 토픽명은 비밀번호가 아닙니다. 추측하기 어려운 긴 이름을 사용하고 민감한 정보는 보내지 마세요. ntfy를 사용하지 않으면 secret을 비워 두면 됩니다. 이 알림은 요청하신 카카오톡/브라우저 웹푸시 대신 사용하는 가장 쉬운 대안입니다.

## 6. 갤럭시 / 아이폰 홈 화면 추가

### 갤럭시 (삼성 인터넷 또는 Chrome)
1. 배포 주소를 엽니다.
2. 오른쪽 위 `⋮` 메뉴를 누릅니다.
3. `홈 화면에 추가` 또는 `앱 설치`를 누릅니다.

### 아이폰 (Safari)
1. Safari로 배포 주소를 엽니다.
2. 아래쪽 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 누르고 `추가`를 누릅니다.

## 7. 자주 생기는 문제

- 목록이 비어 있음: API 키, 기업마당 신청 승인, API 응답 필드 변경, 보수적 필터 조건을 확인하세요. 비어 있다고 실제 지원사업이 없다는 뜻은 아닙니다.
- 업데이트가 안 됨: GitHub 저장소의 `Actions`에서 실패 로그를 확인하세요.
- 설치 메뉴가 안 보임: 반드시 HTTPS로 배포한 주소를 열고, 아이폰은 Safari를 사용하세요.
- 상세 설명/자격: 앱 요약은 참고용이며, 공고 원문과 담당 기관 안내가 최종 기준입니다.
